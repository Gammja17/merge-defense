# OVERRIDE (오버라이드)

세로형 머지 타워디펜스. 내려오는 캡슐을 쏴서 기체를 얻고, 같은 기체를 합쳐 스킬을 진화시키며 외계 함대를 막는 게임.

- 플레이: https://gammja17.github.io/merge-defense/
- 20개 구역, 100 스테이지. 구역 7부터 구역마다 판 규칙 (부서진 칸, 옆에서 오는 캡슐, 귀한 캡슐, 쌍둥이 적, 안개, 정전, 재생, 급류, 분열, 운석 낙하, 역풍)
- 스테이지마다 함대 성격 (대형, 물량, 고속, 보호막, 포격): 맞는 기체로 편성하면 유리
- 구역 보스는 벽: 질 때마다 보스가 약해지고, 여섯 번 지면 치명 기믹을 안 써요
- 기체 등급 (일반, 고급, 희귀, 영웅, 전설), 설계도로 제작과 Mk.10까지 강화 (짝수 Mk마다 이정표)
- 보급 상자 (뽑기, 천장 60번, 확률 공개), 매일 무료 상자, 교환소, 다이아 (지금은 플레이로만 얻음)
- 기체 레벨마다 새 스킬 (쌍발 → 확산 → 관통 → 대형 빔 등), Lv6부터 초월
- 강화: 일반, 고급, 전설 등급. 같은 갈래(공격, 방어, 보급, 특수) 강화를 3개 모으면 시너지
- 중간 보스: 스테이지 가운데쯤 나오고, 잡으면 전설 강화를 골라요
- 격노: 보스 체력이 절반 아래로 떨어지면 더 자주 쏘고 부하를 빨리 불러요
- 무한 방어선, 오늘의 도전, 주간 도전 (온라인 순위표)
- 계정 레벨: 판이 끝날 때마다 경험치, 레벨 보상으로 코어, 강화 해금, 칭호, 칸 바닥 무늬
- 배속 ×2, 저장 코드로 다른 기기에서 이어 하기
- 개인정보 처리방침: [privacy.html](privacy.html)
