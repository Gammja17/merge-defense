# 온라인 순위표 설치 (구글 시트)

1. PC 브라우저에서 개인 구글 계정으로 **https://script.google.com** 에 들어가 **새 프로젝트**를 눌러요.
   (시트의 확장 프로그램 → Apps Script 메뉴로 만들어도 돼요. 메뉴가 막혀 있으면 이 방법으로)
2. 원래 있던 코드를 지우고 `Code.gs` 내용을 통째로 붙여 넣고 저장해요.
3. 순위가 쌓일 시트("OVERRIDE 순위")는 첫 기록이 들어올 때 내 드라이브에 저절로 생겨요.
4. 오른쪽 위 **배포 → 새 배포**를 눌러요.
   - 유형 선택(톱니바퀴)에서 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고, 권한 허용 창이 뜨면 허용해요 ("확인되지 않은 앱" 경고가 뜨면 고급 → 이동).
6. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사해서 알려 주세요.
   게임의 `LB_URL`에 넣으면 순위표가 켜져요.

코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요. URL은 그대로예요.

오늘의 도전 순위는 서버 코드가 이 버전(v: 2)이어야 열려요. 예전 코드가 올라가 있으면 게임은 오늘의 도전 기록을 올리지 않고 "준비 중"이라고만 보여 줘요. 새 `Code.gs`를 붙여 넣고 위처럼 새 버전으로 배포하면, 시트에 `daily` 탭이 생기고 날짜별 순위가 쌓여요.
