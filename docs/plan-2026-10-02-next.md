### 작은 한글 글꼴
- `assets/fonts/PlexKR-Bold-sub.woff2`는 게임에 쓰는 글자만 남긴 파일이에요. `FK(크기)`에서 크기가 17 이하면 이 글꼴을 써요.
- 새 글자를 쓰면 빠진 글자가 생겨요. 아래로 확인하고, 빠졌으면 IBM Plex Sans KR Bold(OFL, Google Fonts) 원본을 받아 `pyftsubset`으로 다시 줄이거나 이름을 바꿔요.
  ```python
  # 코드 문자열 안 한글 중 글꼴에 없는 글자 (주석 제외)
  import glob, re
  from fontTools.ttLib import TTFont
  cmap = TTFont('assets/fonts/PlexKR-Bold-sub.woff2').getBestCmap()
  miss = {c for p in glob.glob('js/*.js') for line in open(p, encoding='utf-8') for c in re.sub(r'//.*', '', line) if '가' <= c <= '힣' and ord(c) not in cmap}
  print(''.join(sorted(miss)) or 'none')
  ```
  지금 빠진 글자: 희, 톨, 냥, 낄 (그래서 "희귀"는 "고급"으로 썼어요).

## 1. 무한 방어선과 오늘의 도전 보상 늘리기 (허락됨)

**문제**: 무한을 어렵게 바꿔서 30웨이브쯤 끝나는데, 끝날 때 코어가 `20 + 웨이브 × 12`라 380쯤밖에 안 돼요. 15분 넘게 한 보상으로 적어요.

**할 일** (`js/05-update.js` `endStage`의 무한 부분)
```js
S.baseEarned = 20 + S.wave * 20 + Math.floor(S.wave / 10) * 100;   // 웨이브마다 20, 10웨이브마다 도달 보너스 100
if (S.daily && PROG.dailyPaid !== S.daily.day) { S.baseEarned *= 2; PROG.dailyPaid = S.daily.day; S.dailyBonus = true; }   // 오늘의 도전: 그날 첫 판은 2배
```
`js/07-screens.js` `drawEarned`의 작은 글씨에 `S.dailyBonus`면 ` (오늘 첫 판 ×2)`를 붙여요.

| 도달 웨이브 | 전 | 후 | 오늘의 도전 첫 판 |
|---|---|---|---|
| 10 | 140 | 320 | 640 |
| 20 | 260 | 620 | 1,240 |
| 30 | 380 | 920 | 1,840 |

**완료 기준**: `#shot-endless`, 결과 화면 오류 없음. 결과 창 스크린샷에서 문구 확인.

## 2. 배속 버튼

**문제**: 쉬운 구간도 그냥 기다려야 해서 지루해요.

**할 일**
- 전투 화면 위쪽 막대(일시정지 버튼 근처)에 `×1 / ×2` 버튼. 누를 때마다 바뀌고, `PROG.settings.speed`에 저장해서 다음 판에도 유지.
- 게임 루프(`js/08-input.js` `loop`)의 `gdt`에 곱해요. 보스 등장 연출, 기체를 드는 동안 느려지는 것, 포격 조준 같은 기존 감속은 그대로 곱해져요.
- 튜토리얼(`S.tut`) 동안은 ×1로 고정하고 버튼을 숨겨요.
- 아이콘은 글자 대신 화살표 두 개(▶▶) 모양으로. 너무 작지 않게 (손가락 44px 이상).

**주의**: `update(dt)`가 한 프레임에 dt를 두 배로 받으면 빠른 탄환이 적을 뚫고 지나갈 수 있어요. ×2일 때는 `update(gdt / 2)`를 두 번 부르는 식으로 나눠서 돌려요.

**완료 기준**: 오류 없음. 시뮬은 영향 없음(시뮬은 루프를 안 써요). 버튼 스크린샷.

## 4. 강화 시너지

**목표**: 강화를 고를 때 "이걸 모으면 뭐가 된다"는 계획이 생기게.

**할 일**
- 갈래(`cat`: 공격, 방어, 보급, 특수) 마다 같은 갈래 강화를 3개 모으면 시너지가 켜져요. 예:
  - 공격 3: 치명타가 터지면 작은 폭발
  - 방어 3: 웨이브마다 기지 보호막 +1, 기체 체력 전부 회복
  - 보급 3: 캡슐 깔 때 10% 확률로 하나 더
  - 특수 3: 사령관 게이지 시작 50
- 강화 고르는 화면(`drawPerk`)의 갈래 이름표 옆에 `공격 2/3`처럼 진행도. 3이 되는 카드는 테두리를 반짝여서 알려 줘요.
- 시너지가 켜지면 배너와 효과음 (효과음은 청음 페이지로 주인이 고르게).
- 화면 아래 "지금 가진 강화" 칩이 많아지면(무한에서 20개 이상) 화면 밖으로 나가요. 같은 강화는 `×3`처럼 합치고, 갈래별 한 줄로 줄여요.

**완료 기준**: 시뮬 승률이 지금과 비슷하게 (232판 중 165~185승, 무한 30~36). 시너지가 너무 세면 숫자를 줄여요.

## 추가 (2026-10-02 오후, 주인 피드백 반영)

- **강화 시너지는 뺐어요** (주인: 너무 많다). 가진 강화 칩을 갈래별 한 줄로 줄인 것은 남김.
- **특수 합체** `FUSE`: 짝꿍 두 기체가 둘 다 Lv8이면 하나를 다른 하나에 겹쳐 합친다. 남는 기체(keep)의 공격 + 특수 능력, 화력 ×1.6, 체력 ×1.5, 더 합치지 않음.
  방패 드론 + 레이더 = 이지스 지휘함, 레이저 + 전자전기 = 번개 요격기, 미사일 + 중력포 = 특이점 포대, 저격기 + 빙결포 = 절대영도 저격기, 방공포 + 화염방사기 = 화염 산탄포, 드론 모함 + 수리 드론 = 정비 모함.
  판에서 짝꿍 Lv8 둘은 금빛 선과 "특수 합체" 이름표로 이어지고, 합친 기체는 금테와 짝꿍 그림 육각. 격납고 카드에 짝 한 줄. 그림은 임시 (VARCO로 그리면 6장).
- **합칠 짝 표시**: 같은 종류 같은 레벨 짝이 있으면 초록 ▲. 기체를 짧게 탭하면 짝꿍 1.5초 강조.
- **정지장**: 전장 오른쪽 아래 모래시계 버튼. 웨이브마다 한 번, 5초 동안 적, 적 공격, 캡슐, 아군 사격이 멈춤 (`S.holdT`).
- **OR 캡슐**: 한쪽을 고르면 다른 쪽은 반투명해지고 맞지 않음 (`capGhost`).
- **무한 난이도**: 초반 적 체력 1.5배 (`ENDLESS_BASE` 1.35, `ENDLESS_GROWTH` 1.29), 보스 체력은 그 웨이브 적 체력에 맞춤 (`ENDLESS_BOSS` 0.17). 11웨이브부터 정예 (`AFFIX`: 가속, 장갑, 분열, 자폭).
- **보스 기믹 (못 피함)**: 보스, 중간 보스가 나오고 2.6초 뒤 칸 하나 영구 봉쇄 (그 칸 기체는 사라짐). 격노하면 1.2초 뒤 무작위 기체 분해. 봉쇄 칸이 있으면 강화 후보에 "긴급 복구". 지연은 게임 시간 `later()`.
- 시뮬: 캠페인 2~30 232판 중 157승 (봉쇄, 분해 때문에 3~6구역이 조금 어려워짐), 무한 봇 20~29웨이브 (보스, 중간 보스에서 고비).
